# How to Run

1. Activate the Python environment
2. Run the `setup.py` script
3. Build the C++ executable (using `./build.sh`)
4. Run the executable.
   -> Output produced: report in `./output/meta.csv` and files named like `n10/sample0.csv`
5. Plot the results using `./plot.py`
   -> Plots produced: in `./plots` with comparisons with other algorithms
